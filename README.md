# Chess_Stats_Retriever
A simple class i'm working on to track progress of a chess.com account

## Install

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then run:

```bash
git clone https://github.com/walup/chess-stats-retriever.git
cd chess-stats-retriever
uv sync
```

To open the notebooks:

```bash
uv run --with jupyter jupyter lab
```
